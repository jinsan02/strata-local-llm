# desktop-5070 STRATA 실험 착수 준비 계획

## Context
기획서(`RTX_5070_Ti_로컬_LLM_추론_최적화_실험_기획서.md` v2.0)를 실행하기 전에, 본체(Tailscale <본체 Tailscale 주소>, SSH 별칭 `desktop-5070`, 사용자 jinsan)의 실측 사양과 STRATA 공식 문서(v0.2.15 기준)를 대조했다. 결과는 아래와 같다. 이 계획은 3.3 착수 게이트 1~3단계와 환경 준비까지만 다룬다. 모델 다운로드와 B0 측정은 `--plan` 결과를 확인한 뒤 진행한다.

## 2. 기획서 검토 결과
**맞는 부분**
- 3.2절에서 Qwen3.6-35B-A3B를 우선한 것은 맞다. MODELS.md 기준으로 `qwen36 UD-Q4_K_XL`(22.9GB, RAM 32GB 기준 설계)만 이 PC 사양에 정식으로 맞는다. 16GB 카드에서는 hybrid 모드(일부 expert만 VRAM에 둠)로 실행된다.
- Flash-Next Q2_0/IQ2_XS는 RAM 기준(expert + 약 10GB = 44GB 이상)을 충족하지 못한다. Unsloth·NVFP4·IQ3 계열도 불가능하다. Coder IQ1_M은 저RAM 모드라서 expert 대부분을 SSD에서 읽기 때문에 느리다. 후보 순서는 그대로 두면 된다.

**수정하거나 보완할 부분**
1. **M0 후보 확정**: `--family qwen36 --model UD-Q4_K_XL`을 1순위로 명시한다. Coder IQ1_M은 SSD 의존 비교용 진단 후보로 둔다.
2. **동시 요청 1개 고정**: 16GB 카드에서는 setup이 기본으로 `--parallel 2`·32K를 제안한다. B0는 '배포 기본값'과 '기획 조건(parallel 1, 8K)'을 구분해서 둘 다 기록한다.
3. **KV 정밀도 탐색(6.2)**: qwen36 경로의 KV는 fp32 고정이다(토큰당 약 45KB, 8K에서 약 0.37GB). 조정 가능한 옵션인지 고정 리비전에서 확인하고, 옵션이 없으면 탐색 항목에서 제외하고 엔진 수정 후보로 옮긴다.
4. **튜닝 변수 목록 구체화**: 실제 존재하는 항목만 넣는다. `--prefill`, `--chunk`, `--mtp 0|2`, `--parallel`, `--batch`, `STRATA_Q36_READ_WINDOWS`, `STRATA_Q36_CHUNK`, `strata launch --tune quick|thorough`, `--calibrate`. 그리고 hybrid 모드에서 VRAM에 두는 expert 수를 6.2에 반영한다.
5. **맞춤 양자화(6.3) 위험**: 원본이 Unsloth `Qwen3.6-35B-A3B-MTP-GGUF`이다. BF16 원본은 약 70GB로 RAM 32GB를 넘는다. 따라서 (a) MTP 텐서를 보존한 채 llama.cpp `llama-quantize`가 처리되는지, (b) STRATA가 Unsloth 이외의 GGUF를 받는지를 소형 검사로 먼저 확인한다. 변환 전에 페이지 파일을 늘린다(사용자가 직접 변경).
6. **빌드 조합 고정**: CUDA 13.0~13.2는 VS2022 Build Tools와, 13.3은 VS2026과 맞춘다. 권장 조합은 **VS2022 Build Tools + CUDA 13.2**이고 `-DCMAKE_CUDA_ARCHITECTURES=120`으로 빌드한다. 기본 목표가 RTX 50이므로 이 PC와 맞는다.
7. **E0 정의**: 설치형 바이너리(`install.ps1`)와 소스 빌드 바이너리를 구분한다. 엔진 수정(E1)은 소스 빌드여야 가능하므로 E0도 **같은 커밋의 소스 빌드**로 정한다. 설치형은 참고용으로만 기록한다.
8. **측정 위생(7.2)**: 전원 구성표를 고성능으로 바꾸고, 유휴 상태의 가용 RAM을 기록하고, 백그라운드 프로그램을 정리한다. 이 단계를 체크리스트에 추가한다.

## 3-0. 백그라운드 정리 (가장 먼저 실행)
GUI 세션 사용자(AzureAD 노진산, 세션 3)가 실행한 프로세스를 SSH(jinsan, 관리자 권한)에서 정리한다. 설치된 프로그램은 삭제하지 않는다.
- **종료(taskkill /F)**: Discord, steam·steamwebhelper, NexonPlug, RiotClientServices, ms-teams, copilotapp·copilotapphost, MythCool, NVIDIA Overlay, RadeonSoftware·AMDRSSrcExt, lghub_system_tray, PhoneExperienceHost, ChatGPT/Codex(ChatGPT.exe, codex, codex-computer-use-swift). 예상 회수량은 약 6~7GB다.
- **시작 프로그램 해제**: Discord, Steam, NexonPlug, RiotClient, Teams, SOOPLiveLauncher, LGHUB. 작업 관리자의 '사용 안 함'과 같은 방식으로 해당 사용자 하이브의 `StartupApproved\Run` 값을 비활성(03)으로 바꾼다. Teams는 MSIX StartupTask를 비활성화한다. 변경 전 값은 `C:\strata-lab\env\startup-backup.reg`로 백업한다. KakaoTalk, Riot Vanguard(안티치트), Tailscale, 오디오·보안 항목은 유지한다.
- 정리 전후의 가용 RAM, Committed, GPU 사용 메모리를 기록한다. 정리 명령은 `C:\strata-lab\cleanup.ps1`로 저장해 측정 전마다 다시 실행한다.

## 3. 준비 작업 (승인 후 SSH로 원격 실행)
작업 루트는 `C:\strata-lab\`로 한다. 하위 폴더는 `engine\`(clone), `data\`(Strata-data), `runs\`(원시 로그), `env\`(사양 기록)이다.
1. 사양 기록: 위 실측값을 `C:\strata-lab\env\hw-20261118.md`로 저장한다.
2. 도구 설치(관리자 권한이 필요하며 원격에서 실행):
   - VS 2022 Build Tools: C++ 워크로드(`Microsoft.VisualStudio.Workload.VCTools`, Windows SDK 포함)를 공식 bootstrapper `--quiet`로 설치한다.
   - CUDA Toolkit 13.2: NVIDIA 공식 설치 파일로 설치한다. 이미 616.92가 있으므로 드라이버 구성요소는 제외한다.
   - CMake, Ninja
   - **Python 환경은 conda로 관리한다.** Miniconda를 공식 설치 파일로 `C:\ProgramData\miniconda3`(AllUsers, silent)에 설치해 SSH 사용자와 GUI 사용자가 함께 쓰게 한다. 이어서 `conda create -n strata python=3.12`를 실행한다(변환·평가·측정 스크립트용). 패키지는 `C:\strata-lab\env\strata-env.yml`로 고정한다.
   - 모든 다운로드는 공식 배포처에서만 받고, 다운로드 전에 파일명·크기를 알린다.
3. STRATA 소스: `git clone https://github.com/Niko1221/Strata` 후 **v0.2.15 태그로 checkout**하고 커밋 해시를 기록한다.
4. 빌드: `cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DSTRATA_ENABLE_CUDA=ON -DCMAKE_CUDA_ARCHITECTURES=120` → `cmake --build build --target strata -j16`. 빌드 옵션과 툴체인 버전을 기록한다.
5. 다운로드 전 계획 확인: `strata launch --plan --family qwen36 --model UD-Q4_K_XL`과 `--family coder --model IQ1_M`을 실행해 파일 목록·크기·메모리 예산을 저장한다. **실제 모델 다운로드(약 23GB)는 결과를 보고한 뒤 진행한다.**
6. 사용자에게 요청할 항목(시스템 설정이라 직접 변경 필요): 전원 구성표를 고성능으로 변경, 페이지 파일 확대(예: 64GB, 양자화 단계 전까지).

## 4. 검증
- `nvcc --version`이 13.2를 보고하고 `cl`이 vcvars64 환경에서 동작하는지 확인한다.
- STRATA 빌드 산출물이 실행되고 GPU(sm_120)를 인식하는지 확인한다.
- `--plan` 출력에서 qwen36 UD-Q4_K_XL이 hybrid 모드로 8K, parallel 1 조건을 수용하는지 확인한다.
- 모든 버전·해시·명령을 `C:\strata-lab\env\`에 남긴다. 이것으로 기획서 13절 '환경·호환성 명세' 초안을 만든다.
