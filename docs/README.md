# docs — 설계 · 규칙 · 실험 문서

진행 상태와 결정은 루트 `STATE.md`, 폴더 지도는 `STRUCTURE.md`, 결과 요약은 `reports/` 에 있다.
문서는 옮기거나 지우지 않는다(커밋 메시지 · 원장 · 다른 문서가 경로로 가리키기 때문). 대신 아래 표에서 **지금 기준인지, 지난 기록인지**를 표시한다.

상태: **기준** = 지금 따르는 규칙 · 계획 · **진행** = 진행 중인 실험의 설계 · **결과** = 끝난 실험의 설계와 결과 · **기록** = 지난 계획이나 조사(새 문서로 대체됨, 고치지 않음)
