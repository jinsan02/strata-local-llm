### 판단

- **실사용 주 경로는 워커(우리 하네스)다.** 같은 모델로 Claude Code 클라이언트는 하네스보다 통과가 크게 낮다(3/16 vs 약 14/16). 차이는 모델이 아니라 클라이언트 쪽(긴 시스템 프롬프트 · 범용 도구 · 막힌 명령 · 턴 낭비)에서 온다.
- Claude Code + 로컬 모델은 대화형 보조(읽기 · 작은 수정 · 테스트 돌리기)로만 쓴다. 더 쓰려면: 허용 목록에 `python -m pytest` 변형(파이프 없는 `-x -q` 등)과 읽기 전용 명령을 넓히고, 테스트 파일 수정을 막는 설정을 따로 본다.
