### 원인: 클라이언트가 모델에게 준 도구가 Read · Edit 둘뿐

- stream-json 첫 줄(init)의 도구 목록이 `["Edit","Read"]` 였다. `CLAUDE_CODE_SIMPLE=1`(프롬프트 15.6K → 1.25K 토큰)은 도구를 **Bash · Read · Edit** 로 줄이는데, X4 는 Bash 를 막았다. 그래서 `--allowedTools` 의 Write · Glob · Grep 은 처음부터 없었다.
- 파일 목록을 볼 방법이 없어 모델이 경로를 추측했다. 13건 기록의 도구 오류 상위: "File does not exist" 122, "old_string 과 new_string 이 같다" 24, 입력 형식 오류 10, 폴더를 Read(EISDIR) 12.
- 40턴 중 상당 부분을 경로 찾기에 썼고, 끝까지 못 가거나(stream 기록이 있는 13건 중 7건 max_turns) 엉뚱한 위치에 새 파일을 만들었다(version_bump r1 은 저장소 최상단에 별도 구현 파일, y6 r1 은 `src/` 밖에 `flask/__init__.py` · `run_tests.py` 를 새로 만들어 import 가 깨짐).
- 따라서 A 경로 4/16 은 **"Read · Edit 만 준 클라이언트"의 값**이다. 모델 · 하네스 비교로 쓰지 않는다.

  - 파이프(`| head`) · 환경 변수 접두사(`PYTHONPATH=src ...`)를 붙인 명령 4번이 허용 목록에 걸려 막혔다 → 지시문에 허용 형태를 적었다.
