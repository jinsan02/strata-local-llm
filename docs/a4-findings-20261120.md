## 2. 원인 후보 (확정 전)

1. **재토큰화**: 모델이 샘플링한 토큰 경계가 BPE 표준 분할과 다르다. 예를 들어 `/*.py`를 다르게 자른 경우다. 텍스트는 같아도 id 가 달라진다.
2. **재렌더링**: 서버가 응답의 `reasoning_content` 를 `.strip()` 하고(`server.py:6999`), 도구 호출도 파싱한 뒤 템플릿이 다시 쓴다. 그래서 모델이 쓴 공백 · 줄바꿈 · 인자 표기가 템플릿의 표준형과 다르면 텍스트 자체가 달라진다.

두 경우 모두 "서버가 생성한 id 를 그 응답의 렌더링 텍스트와 짝지어 둔다"로 고칠 수 있다. 다만 어느 쪽인지 먼저 확인해야 설명과 판정 기준이 정확해진다.

## 3. 확인 방법 (H2a 끝난 뒤, 서버가 비는 시간)

- 서버에 `STRATA_DEBUG=1` 을 주면 응답마다 `raw:`(생성 텍스트) · `raw ids:` 를 로그에 남긴다(`server.py:6727`). 코드 변경은 필요 없다.
- version_bump 를 H2a + card-coding 으로 3회 돌린다(약 10분). 재사용 0 이 난 턴에서 직전 응답의 raw ids 와, 다음 프롬프트를 `tools/strata_tokenizer.py` 로 다시 인코딩한 같은 구간을 비교한다.
  - 텍스트가 같고 id 만 다르다 → 재토큰화.
  - 텍스트가 다르다(공백 · 인자 표기) → 재렌더링.
- 오프라인 비교는 노트북 anaconda base(`regex` 포함, 설치 없음)에 본체의 팩 `tokenizer/` 디렉터리만 복사해서 한다.

## 4. 수정안 (손실 없음 — 모델이 실제로 계산한 KV 를 그대로 잇는다)

위치: 엔진 저장소 `serve/server.py` + `tools/strata_tokenizer.py`(STRATA v0.2.15 c775728, 지금은 수정 없음).

1. `PromptEncoder.remember_reply(prompt_text, plain, prompt_ids, reply_text, reply_ids)`:
   - `reply_text` 는 응답 메시지(assistant: reasoning_content · content · tool_calls)를 서버가 같은 템플릿으로 렌더링한 구간이다. `<|im_end|>` 까지 포함한다.
   - 이 구간을 `prompt_ids + reply_ids(+ im_end)` 와 짝지은 항목으로 저장한다.
   - 경계(mark)는 기존 프롬프트 경계에 '응답 끝' 하나만 더한다.
2. `PromptEncoder.encode` 는 바꾸지 않는다. 다음 요청의 텍스트가 이 항목과 응답 끝까지 같을 때만 그 경계에서 id 를 가져오고, 나머지는 지금처럼 인코딩한다. 클라이언트가 응답을 바꿔 보낸 경우(H0 처럼 reasoning 을 빼는 경우)는 텍스트가 앞에서 갈라지므로 지금 동작 그대로다.
3. 훅: `Service._run` 이 끝날 때(finish == stop/tool_calls, 취소 · 오류 · length 제외) 요청의 prompt 텍스트 · ids 와 `raw_ids` 를 넘긴다. 비스트림 · 스트림 · Responses 경로가 같은 `_run` 을 쓰는지 확인해야 한다.
4. 제외: thinking 상한으로 서버가 끼워 넣은 wrap-up 문장이 있는 턴, 강제 호출(force) 턴, 이미지가 있는 턴. 이런 턴은 기록하지 않아 지금과 같게 동작한다.

## 5. 판정 · 기록

- 정확성: 엔진 저장소 기존 테스트(바이트 토크나이저 대역) + 새 단위 테스트를 둔다. 새 테스트는 (a) 응답 그대로 → 응답 끝까지 재사용, (b) 응답 수정 → 기존 동작, (c) 항목 수 상한이다.
- 효과: version_bump 3회에서 "늘었는데 0" 이 사라지는지 본다. 그다음 X3 6과제 x 5회를 x3h2k 대조로 한 번 돌린다(품질 −1 이내, 시간 · 재읽기 비교).
- 기록: 엔진 패치는 strata-lab 에 패치 파일로 두고, 서버 구성 ID 를 새로 매긴다. 결과가 바뀔 수 있으므로(모델이 쓴 토큰 그대로 이음) "결과 불변"이 아니라 "손실 없음 · 품질 관문"으로 판정한다.
