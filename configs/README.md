# configs — 실행 설정 · 양자화 레시피

run 의 입력을 둔다. 원장의 `config_sha256` 은 run 이 실제로 쓴 config JSON 의 해시다.

| 폴더 | 내용 | 이름 |
| --- | --- | --- |
| `settings/` | (예정) STRATA 실행 설정 S0, S1 … | `S<n>-<요지>.json` |
| `quant/` | (예정) 맞춤 양자화 레시피 M1 … (텐서별 타입 표, 원본 리비전) | `M<n>-<요지>.json` |
| `eval/` | (예정) 탐색 평가 세트 정의 (최종 50문항은 여기 두지 않는다) | |

STRATA 옵션은 엔진 고정 커밋에 실제로 있는 것만 쓴다 (`docs/RULES.md` 1번, 기획서 6.2).
