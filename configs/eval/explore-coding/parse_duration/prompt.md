파이썬 함수 `parse_duration(s: str) -> int` 를 작성하라. 기간 문자열을 초 단위 정수로 바꾼다.

- 단위는 `d`(일), `h`(시), `m`(분), `s`(초). 예: `"1h30m"` -> 5400, `"2d"` -> 172800, `"45s"` -> 45, `"1d2h3m4s"` -> 93784.
- 각 단위는 한 번만, 위 순서(d, h, m, s)로만 나올 수 있다. 숫자는 0 이상의 정수다.
- 앞뒤 공백은 무시한다. 그 밖의 공백, 빈 문자열, 단위 없는 숫자, 순서 위반, 단위 중복, 알 수 없는 단위는 `ValueError` 를 일으킨다.
