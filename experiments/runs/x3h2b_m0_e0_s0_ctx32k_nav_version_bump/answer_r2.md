`src/packaging/version.py` 파일의 `Version` 클래스에 `bump(part: str) -> Version` 메서드를 추가하였습니다.

**수정 내용 요약:**
1.  **메서드 추가**: `Version` 클래스 내에 `bump` 메서드를 정의했습니다.
2.  **인자 검증**: `"major"`, `"minor"`, `"micro"` 외의 값을 받으면 `ValueError`를 발생시킵니다 (대소문자 구분).
3.  **Release 조작**:
    *   요청된 부분(`index`)의 숫자를 1 증가시킵니다.
    *   해당 위치 이후의 모든 Release 숫자는 0으로 초기화합니다.
    *   현재 Release 길이가 부족할 경우(예: `1`에 `micro` 적용), 해당 인덱스에 도달할 때까지 0을 채워 길이를 늘립니다 (예: 결과 `1.0.1`).
4.  **Suffix 제거**: `pre`, `post`, `dev`, `local` 세그먼트는 모두 버리고 삭제합니다. `epoch`는 그대로 유지됩니다.
5.  **반환값**: 변경된 상태를 가진 새로운 `Version` 객체를 반환합니다.

기존 테스트 파일 및 클래스의 기존 동작에는 영향을 주지 않았습니다.
