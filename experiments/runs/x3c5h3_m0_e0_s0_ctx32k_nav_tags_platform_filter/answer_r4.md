`parse_wheel_filename` 함수에 `platforms` 키워드 전용 인자를 추가하고, 파일명이 해당 플랫폼을 지원하는지 검증하는 로직을 구현했습니다. 주요 변경 사항입니다:

1.  **시그니처 수정**: `src/packaging/utils.py`의 `parse_wheel_filename` 함수 시그니처에 `platforms=None` 파라미터를 추가했습니다.
2.  **타입 검사**: `platforms`로 단일 문자열이 전달되면 `TypeError`를 발생시키는 로직을 추가했습니다.
3.  **정규화 및 매칭**:
    *   제공된 플랫폼 목록의 각 문자열을 `.`, `-`, 공백을 `_`로 대체하고 소문자로 변환하는 정규화 작업을 수행합니다.
    *   파일명의 태그 중 `platform`이 `'any'`인 경우 무조건 통과하도록 처리했습니다.
    *   나머지 태그들의 플랫폼 이름이 정규화된 `platforms` 목록과 일치하는지 확인하여, 일치하지 않으면 `InvalidWheelFilename`을 던집니다.
4.  **실행 순서**: 기존 파일 형식 검증(확장자, 버전 등) 및 태그 파싱 완료 후 반환 직전에 이 검사가 수행되도록 코드를 배치했습니다.
