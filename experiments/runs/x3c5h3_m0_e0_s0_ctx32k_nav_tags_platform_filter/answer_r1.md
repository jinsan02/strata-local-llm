**수정 내용 요약**

`src/packaging/utils.py` 파일에 있는 `parse_wheel_filename` 함수를 다음과 같이 수정하였습니다:

1.  **시그니처 변경**: 함수에 키워드 전용 인자 `platforms=None`을 추가했습니다.
2.  **로직 구현**: `platforms` 인자가 제공된 경우 (`None`이 아닌 경우), 기존 태그 검증(`parse_tag`)이 완료된 후 다음 로직을 수행합니다:
    *   `platforms`가 문자열(`str`)인 경우 `TypeError`를 발생시킵니다.
    *   제공된 플랫폼 이름들을 정규화합니다 (`.` · `-` · 공백을 `_`로 바꾸고 소문자로 변환).
    *   휠 파일의 태그 집합(`tags`) 내에서 다음 조건이 만족되면 통과시킵니다:
        *   태그 중 하나라도 플랫폼이 `any`인 경우 (빈 iterable 포함).
        *   태그의 플랫폼 이름이 정규화된 사용자 제공 플랫폼 목록과 일치하는 경우.
    *   위 조건을 모두 만족하지 못하면 `InvalidWheelFilename`을 발생시킵니다.
