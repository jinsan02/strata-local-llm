**주요 내용:**
- `canonicalize_version`의 현재 동작을 고정하는 124개 테스트 케이스 작성
- **기본 동작**: 일반 버전 문자열(`"1.0.1"` → `"1.0.1"`, `"1.0.0"` → `"1"`)
- **`strip_trailing_zero` 옵션**: `True`(기본)는 뒤따르는 `0` 제거, `False`는 원본 유지
- **잘못된 버전 문자열**: `"foo bar baz"`, `"lolwat"` 등은 그대로 반환
- **`Version` 객체 입력**: 객체 자체를 전달해도 동일하게 동작
- **세그먼트별 처리**: epoch(`1!0.0`→`1!0`), pre(`1.0a0`→`1a0`), post(`1.0.post0`→`1.post0`), dev(`1.0.dev0`→`1.dev0`), local(`1.0+abc`→`1+abc`) 모두 정확히 유지
- **복합 세그먼트**: epoch+pre+post+dev+local이 혼합된 버전도 각 부분별로 올바르게 처리
- **경계 사례**: 단일 `"0"`, 내부 0(`"1.0.1"`), 다중 0(`"1.0.0.0.0"`→`"1"`), 대수치 등

모든 테스트가 현재 코드에서 통과하며, 함수나 관련 코드(`Version._trim_release`, `Version.__str__`)가 변경되면 실패하여 문제를 알림.
